## 🛠️ Technical Skills Matrix

### 🌐 Networking & Routing Protocols
* **Routing:** OSPFv2 / OSPFv3, EIGRP (Classic & Named Mode), BGP (eBGP & iBGP), Policy-Based Routing (PBR), Static Routing with IP SLA.
* **Switching & L2:** Spanning Tree (STP, RSTP, MST, PVST+), 802.1Q Trunking, VLANs, LACP EtherChannel, vPC (Virtual Port Channels).
* **Data Center:** VXLAN EVPN fabrics, Nexus Dashboard Fabric Controller (NDFC), Cisco NX-OS architecture.

### 🔒 Network Security & Hardening
* **Infrastructure Defense:** Control Plane Policing (CoPP), Dynamic ARP Inspection (DAI), IP Source Guard (IPSG), DHCP Snooping, Port Security, uRPF.
* **Access Control & Identity:** Standard/Extended ACLs, PACLs, VACLs, AAA (TACACS+ / RADIUS), RBAC.
* **Analysis & Diagnostics:** Wireshark deep packet inspection, Embedded Packet Capture (EPC), SPAN/RSPAN/ERSPAN, FIA Packet-Trace.

### ☁️ Cloud, Virtualization & Systems
* **Hypervisors & OS:** VMware ESXi / vSphere, Proxmox VE, Cisco IOS, IOS-XE, NX-OS, Ubuntu Server, Debian, RHEL.
* **Containers & DevOps:** Docker, Kubernetes, Linux CLI, Bash scripting, Python (Netmiko / Scrapli), Git / GitHub Actions.
