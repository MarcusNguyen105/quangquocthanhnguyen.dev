## 👨‍💻 About Quang Quoc Thanh Nguyen

I am a Network & Systems Engineer passionate about designing resilient, high-performance network infrastructures, automating network operations, and securing distributed systems.

### Core Focus Areas:
* **Enterprise Infrastructure Design:** Building scalable multi-layer campus and datacenter fabrics using Cisco IOS-XE and NX-OS.
* **Security Engineering:** Defense-in-depth network hardening, zero-trust architectures, and traffic anomaly monitoring.
* **Automation & DevOps:** Infrastructure-as-code, automated network telemetry, and containerized cloud services.
