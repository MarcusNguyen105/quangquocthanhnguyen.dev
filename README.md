# QuangQuocThanhNguyen.dev - Technical Documentation & Knowledge Base

Modern, high-performance developer documentation portal and digital garden built with **Astro v5+** and **Starlight**.

## 🚀 Features

- **Obsidian & Glassmorphism Design:** Deep cyber-slate background with vibrant electric cyan and neon purple accents.
- **Ultra-Fast Global Search:** Client-side full-text search with `Ctrl+K` modal powered by **Pagefind**.
- **Categorized Knowledge System:** Software Architecture, Cloud & DevOps, AI/ML Systems, Cybersecurity, and Cheat Sheets.
- **Zero-Latency Static Generation:** Blazing fast load times with static prerendering.
- **Automated CI/CD:** GitHub Pages / Cloudflare Pages ready.

## 🛠️ Local Development

```bash
# 1. Install dependencies
npm install

# 2. Run local dev server
npm run dev

# 3. Build for production (generates static output + Pagefind search index)
npm run build

# 4. Preview production build
npm run preview
```
